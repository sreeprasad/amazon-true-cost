# Amazon True Cost 🛒 🏴‍☠️

**Built for Punk Software Hack Night**

Corporate walled gardens hold your purchase history hostage, obfuscating aggregate data while serving you highly optimized product images to drive algorithmic impulse buying. 

**True Cost** is a local-first Chrome extension that violently injects transparency back into your Amazon order history. No cloud processing, no telemetry, and absolutely no external LLM APIs. Just local DOM scraping, hostile visual moderation, and raw data liberation. 

Software that belongs to you, running entirely on your machine.

## Installation

Because this is punk software, it is not in the Chrome Web Store. You run it locally.

1. Clone this repository or download the source folder.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Toggle **Developer mode** on in the top right corner.
4. Click **Load unpacked** and select the `amazon-true-cost` directory.
5. Navigate to `amazon.com/your-orders` and watch the DOM get hijacked.
